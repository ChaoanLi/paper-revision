# Revision plan

Order of work: **freeze the method → code → experiments → writing → letter → checks → submit.**
No manuscript text is drafted for a part whose experiments are not finished.

## Phases

| Phase | Goal | Steps |
|---|---|---|
| A. Decide | Agree on what changes and what is declined; settle positioning | |
| B. Method & code | Freeze the method; fix code; tag the code version | |
| C. Experiments | Run every requested analysis (even those that end up only in the letter) | |
| D. Writing | One proposal per change, section by section | |
| E. Letter | Draft each reply as its change is applied; finalize after all changes | |
| F. Checks | Numbers, math kept, style, citations, pages, latexdiff, mock re-review | |
| G. Submit | Clean PDF, marked PDF, letter, supplement, code package | |

## Steps

Placement: `main` (main text, essentials only) · `supp` (supplement) · `letter` (response only).
