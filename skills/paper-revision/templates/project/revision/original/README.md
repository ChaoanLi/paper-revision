# original/

The decision letter and every report, verbatim, one markdown file each. Never edit these after
intake; interpretation goes to `../comments.md`.

| File | Content |
|---|---|
| `decision-letter.md` | Editor's email: decision, deadline, procedural requests (become `ED-1`…) |
| `AE.md` | Associate editor's report (`AE-1`…) |
| `R1.md`, `R2.md`, … | One file per reviewer (`R1-1`…, or `R2-M1` / `R2-m1`) |
| `*.pdf` | Any report received as PDF, kept next to its markdown transcription |

At the top of each file:

    Source: email of YYYY-MM-DD / PDF attachment <name>
    Received: YYYY-MM-DD

Then the text exactly as received, with each comment preceded by its ID in bold, e.g.
`**R1-3**`. Keep the reviewer's own numbering in the text; the ID is added, nothing removed.
Reports are confidential: this folder is never committed or shared.
